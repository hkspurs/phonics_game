# 《太空中文字保衛戰》設計規格

## 文件狀態

- **版本**：0.1
- **日期**：2026-08-12
- **狀態**：設計已獲批准，等待 spec review
- **首個目標**：可放上現有 GitHub Pages、可在手機／平板／電腦橫向遊玩
- **變更記錄**：v0.1 — 建立 MVP 設計，確定 Phaser-only 遊戲畫面及 GPT-SoVITS 離線聲音流程

## 1. 產品摘要

《太空中文字保衛戰》係現有 phonics game 入面一條獨立嘅常用中文字遊戲 route。小朋友駕駛可愛卡通太空戰機，聽到一個粵語常用詞語後，控制戰機左右移動並開火，射中三個移動目標中顯示相同詞語嘅目標。

第一版使用繁體中文介面、粵語預錄 MP3、三個主題篇章及 10 題短局。遊戲畫面全部由 Phaser 負責；React 只負責掛載及銷毀獨立 route，唔改變原有拼音遊戲流程。

## 2. 設計支柱

1. **先聽清楚，再快速辨認**：讀音完成後先開始 8 秒挑戰。
2. **操作簡單**：左右移動、按住開火，適合小朋友及觸控裝置。
3. **失敗可理解**：射錯及超時會清楚顯示受傷，但錯誤目標唔會消失或洩露答案。
4. **短局完成感**：10 題一局，完成後即時顯示表現及獎勵。
5. **場景服務學習**：學校、公園、家庭主題只用作辨識及動機，不增加多餘系統。

## 3. 已確認範圍

### 3.1 內容

- 粵語讀音。
- 每題播放完整詞語一次，例如「老師」。
- 保留使用者提供嘅字形，包括「户外」及「起牀」。
- 三個篇章由小朋友自行選擇：學校篇、公園篇、家庭篇。
- 每篇章現有清單各 28 個詞語，共 84 個；第一版生成 84 個 MP3，唔自行補詞至 90 個。
- 每局由所選篇章隨機抽 10 個不重複詞語。
- 每題另外隨機抽同篇章內 2 個不同詞語作錯誤目標。

### 3.2 遊戲及裝置

- 遊戲以橫向畫面為主。
- 直向裝置顯示「請將裝置轉為橫向」，唔開始遊戲。
- 支援觸控左右按鈕及鍵盤左右方向鍵。
- 支援觸控開火按鈕及鍵盤 Space。
- 按住開火鍵可以連續發射；子彈之間有短暫間隔。
- 遊戲中唔設暫停；離開未完成遊戲會放棄該局，下次重新開始。

### 3.3 貨幣及收藏

- 太空寶石係全新獨立貨幣，唔影響現有鑽石。
- 完成一局 10 題固定獲得 5 粒太空寶石；中途失敗唔派發。
- 三個篇章合共 9 枚徽章，每篇章 3 枚：普通、稀有、特別。
- 徽章價格：普通 5 粒、稀有 15 粒、特別 30 粒。
- 每枚徽章只可兌換一次；已擁有徽章顯示「已獲得」。
- 太空寶石及徽章沿用現有 Zustand/localStorage 持久保存。
- 徽章兌換入口位於常用中文字主畫面及完成結果畫面。

## 4. 核心遊戲流程

### 4.1 進入及教學

1. 現有主畫面新增「常用中文字」卡片。
2. 進入 `/chinese-space` 後顯示《太空中文字保衛戰》主畫面。
3. 主畫面提供篇章選擇及徽章兌換。
4. 第一次遊玩顯示簡短教學：左右移動、按住開火、聽詞語後射中答案。
5. 教學題不扣 HP；教學完成狀態持久保存。

### 4.2 每局

1. 小朋友選擇一個篇章。
2. 系統抽取 10 個不重複正確詞語，並為每題建立 2 個同篇章錯誤詞語。
3. 每局開始時戰機 HP 設為 3 格；HP 會跨題保留，直到完成或歸零。這個解讀符合完成頁需要顯示「剩餘 HP」及 HP 歸零即結束嘅設定。
4. 題目開始時 3 個目標同時出現於左、中、右三條固定航道；正確答案航道每題隨機。
5. 自動播放一次粵語詞語。播放期間可以左右移動，但唔可以開火。
6. 粵語播放完畢後開始 8 秒倒數，並顯示大號數字及圓形進度條。
7. 三個目標慢速向下移動，但保持於可射擊範圍內；唔會因到達畫面底部而消失或攻擊戰機。

### 4.3 射擊結果

#### 射中正確目標

- 停止倒數。
- 播放短促開心提示音及目標爆炸音效。
- 記錄該題由第一次倒數開始至正確命中嘅反應時間；不計粵語 MP3、音效及畫面動畫播放時間，但累計射錯／超時後各次實際倒數時間。
- 短暫顯示成功效果後進入下一題。

#### 射中錯誤目標

- HP 減 1。
- 播放短促受傷／碰撞音效。
- 錯誤目標保留，仍可繼續射擊正確答案。
- 同一錯誤目標每題最多只扣一次 HP，受擊後短暫閃爍保護。
- 自動重播粵語詞語；讀音播放完畢後重新數 8 秒。
- 若 HP 歸零，立即進入遊戲結束畫面，不再進行重播。

#### 超時

- 8 秒完結仍未射中正確目標時，HP 減 1。
- 播放戰機受傷／爆炸提示效果及相應音效。
- 自動重播粵語詞語；讀音播放完畢後重新數 8 秒。
- 保留同一題及三個目標。
- 若 HP 歸零，立即進入遊戲結束畫面。

### 4.4 結束狀態

#### HP 歸零

- 顯示「戰機爆炸」畫面。
- 提供「重新挑戰」：由所選篇章第 1 題重新開始。
- 提供「選擇其他篇章」。
- 該局唔派發太空寶石。

#### 完成 10 題

- 顯示平均反應時間、答啱題數、剩餘 HP 及獲得太空寶石。
- 平均反應時間係 10 題反應時間嘅平均值。
- 固定派發 5 粒太空寶石。
- 提供「再玩一次」、「選擇篇章」及「兌換徽章」。

## 5. 場景及視覺方向

- 整體：鮮艷、親切、兒童卡通太空風格。
- 玩家：可愛卡通小型太空戰機，位於畫面下方。
- HP：3 顆心心，受傷後逐粒消失。
- 目標：可愛太空敵人／小隕石，表面顯示大型繁體中文字。
- 正確答案每題隨機位於左、中、右其中一條航道。
- 學校篇：學校太空站、黑板、書包、書本。
- 公園篇：公園星球、草地、樹木、花朵。
- 家庭篇：家庭太空基地、房間、窗戶、桌子。
- 初版使用 Phaser 圖形、文字及簡單粒子效果；避免未必要嘅大型圖片資產。
- 文字需要高對比及大字體，手機橫向仍然清楚。

## 6. 技術架構

### 6.1 邊界

```text
React route /chinese-space
        ↓
Phaser game wrapper
        ↓
單一 Phaser 遊戲 scene，以 screen/state mode 切換
  ├─ 主畫面／篇章選擇
  ├─ 教學
  ├─ 遊戲
  ├─ 結果
  └─ 徽章兌換
```

- React 只負責 route、mount、unmount 及 Phaser 失敗時嘅最小 fallback。
- Phaser 負責畫面、輸入、戰機、目標、子彈、碰撞、倒數、動畫及遊戲音效。
- 瞬時遊戲狀態留在 Phaser：當前篇章、10 題 queue、題目 index、HP、timer、targets、shots、feedback、反應時間。
- 純 JavaScript 模組負責詞語 catalog、題目抽選、結果計算及獎勵規則，方便單元測試。
- Zustand/localStorage 只保存跨 session 狀態：太空寶石、已獲得徽章、教學完成狀態。
- 不保存未完成遊戲；刷新或離開 route 後重新開始。

### 6.2 聲音

- 參考聲音檔：`/tmp/h77yz-65zza.mp3`。
- 檔案檢查結果：MP3、約 173.2 秒（2 分 53 秒）、44.1 kHz、stereo、64 kbps，符合 1–3 分鐘自然對話參考錄音要求。
- 參考錄音只作 GPT-SoVITS input，唔放入 GitHub 或 production assets。
- 使用 GPT-SoVITS CPU 版離線生成 84 個粵語 MP3。
- 因為選擇由工具自行轉錄，生成前後需要檢查 ASR 文字及每個詞語讀音。
- 遊戲只載入所選篇章嘅 28 個詞語音檔，減少首次載入量。
- 音檔檔名需要使用穩定 word ID，而唔使用未清洗嘅中文字作檔名。

### 6.3 GitHub Pages

- 沿用現有 Vite build 及 GitHub Pages deploy script。
- 新 route 必須兼容現有 base path 及 `404.html` fallback。
- 原有 phonics routes、assets、獎勵及鑽石資料不可被新遊戲破壞。

## 9. 驗收及測試

### 純邏輯測試

- 每篇章 catalog 正好 28 個詞語，總數 84。
- 每局抽出 10 個不重複詞語。
- 每題正確答案及兩個錯誤答案互不重複，並來自同篇章。
- 正確航道可以隨機分布於三條航道。
- 錯誤目標每題最多扣一次 HP。
- 每題反應時間只累計實際倒數時間，不計語音、音效及動畫時間。
- 超時及射錯都會扣 HP 並重設同一題嘅 8 秒流程。
- HP 歸零進入 game over；完成 10 題只派發一次 5 粒寶石。
- 徽章價格、一次性兌換及不足寶石狀態正確。

### UI／遊戲測試

- 首次教學顯示，完成後唔再重複顯示。
- 觸控按鈕及鍵盤方向鍵／Space 都可以操作。
- 直向裝置顯示轉向提示；橫向遊戲可開始。
- 音檔播放期間可以移動但不能開火；播放後才開始倒數。
- 正確、射錯、超時、HP 歸零及完成頁均顯示正確 feedback。
- 刷新後太空寶石及徽章保留；未完成局唔保留。
- 原有 phonics routes 及現有測試不受影響。

- 90 個詞語；第一版係 84 個。
- 複雜故事對話或額外角色養成。
- 直向完整遊戲布局。

## 11. 已知依賴及風險

1. **GPT-SoVITS CPU 時間**：可接受較慢生成，但需要先確認 CPU 版環境及模型磁碟空間。
2. **ASR 轉錄質素**：參考錄音不提供逐字稿，生成前後必須人工核對粵語文字及讀音。
3. **參考聲音授權**：只使用使用者確認已獲授權嘅錄音；reference audio 不提交 Git。
4. **繁體字 canvas 字體**：需要在目標瀏覽器確認字體 fallback 及可讀性；必要時使用現有 web font／系統 fallback。
5. **Phaser bundle 大小**：沿用 lazy route，避免影響現有首頁首次載入。
